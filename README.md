# CS 370 Project Two

## Pirate Intelligent Agent

For this project, I worked with a treasure hunt game where a pirate intelligent agent needed to learn how to navigate a maze and reach the treasure. I was given starter code that created the maze environment, handled the pirate's available actions, displayed the maze, built the neural network model, and included helper functions for testing the agent. My main work was completing the Q-training algorithm that trained the pirate using deep Q-learning. The training process used exploration and exploitation, rewards, experience replay, and a target network so that the pirate could improve its decisions over time and successfully solve the maze.

## What do computer scientists do and why does it matter?

The job of a computer scientist is to delve into what more computers can do within the world. Whether it be software development, full stack development, AI training, or building new theories about what computers can create and do, the goal is to evolve what we have already built on. This matters because computer scientists continue to improve the technology people and organizations use every day and find new ways that computers can solve problems.

## How do I approach a problem as a computer scientist?

I start by dissecting each part of the problem. I ask what the problem is, what I need in order to solve it, and what the first thing I should tackle is. Breaking a problem into smaller parts makes it easier for me to understand what needs to happen instead of trying to solve everything at once. In this project, that meant understanding the starter code, identifying what the Q-training algorithm needed to do, testing the model, and continuing to make changes until the pirate could successfully solve the maze.

## What are my ethical responsibilities to the end user and the organization?

I am responsible for making sure that anyone who uses software involving their personal data is protected from potential harm, whether that comes from hackers, cyberattacks, impersonators, or other threats. I also have a responsibility to make sure that the company I work for is being ethical in its decisions about what it does with customers' personal data. Computer scientists should consider both whether a system works and whether the way it handles people and their information is responsible.
